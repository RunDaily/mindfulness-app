## 1. 心锚是什么

心锚用来减少某些应用的无意识打开与超时使用。

你在「方案」里选出要管的应用，并为它们设定规则。之后每次打开这些应用，心锚会在进入前先停下，让你确认这一次是否真的要进、要用多久。

「今日」用来查看今天的使用情况，以及加入方案前后的变化。

心锚不替代系统自带的屏幕使用时间；它侧重的是：**打开前多一步确认，并按你设的规则拦住。**

## 2. 开始使用

### 你需要先完成的设置

心锚要正常工作，至少需要下面两项权限：

| 权限 | 用途 |
|------|------|
| 用量访问 | 统计各应用使用时长与打开次数 |
| 悬浮窗 | 在其它应用上方显示拦截页 |

建议同时开启：

| 权限 | 用途 |
|------|------|
| 无障碍 | 在拦截页出现时，避免用 Home、最近任务等直接绕过 |

以上入口都在「我」页。未齐时，「我」页会提示有几项需处理。

<!-- 图：我 · 权限列表（用量访问 / 悬浮窗 / 无障碍），标出「需开启」状态 -->
**[配图建议]** 「我」页权限列表：三项名称 +「需开启 / 正常」状态。用户应能对照截图找到入口。

### 最短路径

1. 打开「我」，完成用量访问与悬浮窗（建议再开无障碍）。
2. 打开「方案」，添加一个你想少用的应用。
3. 为它设定规则（例如：每天最多用 30 分钟）。
4. 回到桌面，再打开该应用，确认会出现拦截页。

做到第 4 步，说明基本链路已通。

<!-- 图：四步示意可做成一条竖向步骤，不必四张大图；关键是第 4 步拦截页实拍 -->
**[配图建议]** 第 4 步拦截页实拍一张即可；前三步用短步骤列表足够。

### 常见卡点

- **打开应用没有拦截**：先回「我」看权限是否齐全；再确认该应用已在「方案」里且规则已开启。
- **权限都开了仍不稳定**：部分手机厂商会清理后台，见后文「权限与后台保活」。

## 3. 方案：添加应用并设定规则

「方案」是你管理规则的地方：哪些应用要管、每条规则怎么设。

### 添加应用

1. 打开底栏「方案」。
2. 选择添加应用。
3. 从列表中选出要管的应用（列表可参考近 7 日的使用情况）。
4. 保存后，该应用会出现在方案中。

一个应用同一时间只应放在一侧用途里：要么作为「要少用的」，要么作为「想多用的」，不要重复添加。

微信不适合加入需要拦截的名单；选择时会有提示。

<!-- 图：方案空态 → 选择应用列表 → 已加入后的一行 -->
**[配图建议]** 三连小图或一张标注图：空态「添加」→ 选 App → 方案中出现该 App。标注点击热区即可，不要大段旁白。

### 可以设定的规则

加入方案后，可为该应用配置下列规则（以界面名称为准）：

| 规则 | 作用 |
|------|------|
| 日限额 | 当天使用达到设定分钟数后，再打开会被拦住 |
| 打开次数 | 当天打开次数用完后，再打开会被拦住 |
| 打开前等待 | 未触达上面两项上限时，打开前先倒数几秒，再决定是否进入 |
| 时段锁 | 在设定的时间段内不允许进入 |

你不必一次全开。多数情况先设「日限额」，跑通几天后再按需要加其它规则。

<!-- 图：单个应用的配置页，圈出「日限额」「时段锁」等标题 -->
**[配图建议]** 配置页全貌一张，用序号标出各规则区块；正文表格已解释含义，图上不要重复堆字。

### 从方案里移出

在该应用的配置中选择移出方案后，心锚不再拦截它。历史记录仍可能保留在「今日」或详情中供查看，但不会再挡打开。

### 名额

要少用的应用、想多用的应用，各有数量上限（当前各最多 3 个）。满了需要先移出一个，再添加新的。不必第一天就填满。

## 4. 打开应用时会发生什么

当某个应用已在方案中且规则生效时，从桌面或其它应用再次打开它，会先看到拦截页，而不是直接进入。

### 拦截页上你可以做什么

取决于当前规则与应用类型，拦截页通常提供这些选择（措辞以实机为准）：

- **先等几秒再决定**（若开启了打开前等待）
- **不进去了 / 离开**：关闭拦截，不进入该应用
- **搜索后直达**（部分应用支持）：输入关键词后跳到应用内搜索结果，适合「只查一件事」
- **写下要做什么并选择时长后进入**：只给这一次使用设一个时限
- **确认有事再进入**（部分应用）：先劝离，再选一个较短的本次时长

触达「日限额」或「打开次数」上限后，拦截页会明确提示今日已用完，此时通常只能离开，不能再进入。

<!-- 图：A 打开前等待中的拦截页；B 今日时长已用完的拦截页 -->
**[配图建议]** 至少两张对比图：（1）可继续进入的确认态；（2）次数或时长用尽的硬拦态。比文字更能消除「拦截是坏了吗」的误解。

### 关于系统返回键与 Home

拦截页出现期间，用 Home、最近任务或返回键，一般不会真正关掉拦截；心锚会把你拉回拦截页。

若希望这项行为稳定，请开启「无障碍」。

离开拦截的正常方式，是点页面上的离开类按钮，而不是靠系统手势「躲过去」。

### 你怎么判断规则生效了

- 规则写「每天 30 分钟」，今天已用满 → 再打开应看到时长用尽的提示，且不能进入。
- 规则写了打开前等待 → 未用满时，应先看到倒数，倒数结束前不能直接进入。
- 规则写了某时段锁定 → 在该时段内打开，应被拦住。

若与上述不符，优先检查权限与该应用是否仍在方案中。

## 5. 今日：查看使用情况

「今日」用来看效果，不负责改规则。改数字请回「方案」。

### 还没有加入任何应用时

「今日」会展示这台手机近 7 日用得较多的应用（需要已开启用量访问）。点某一行可查看概况；底部可点「去方案添加」，把想管的应用加入方案。

若尚未授权用量访问，页面会提示先授权，否则看不到近 7 日列表。

<!-- 图：今日 · 无规则时的近 7 日列表 +「去方案添加」 -->
**[配图建议]** 无规则态一张：列表 + 底部「去方案添加」。

### 已有规则时

「今日」主列表变为方案中的应用，每行大致显示：

- 应用名称
- 今日已用时长（若设了日限额，会显示「已用 / 限额」）
- 今日打开次数（若设了次数上限，会显示「打开 a / b」；用尽时会标出）

点某一行进入该应用的详情。

下方可能还有一条「今天」摘要入口（例如守住几次、进入几次），用于回看今天在拦截页上的选择，不是改规则的地方。

<!-- 图：今日 · 有规则列表，圈出「已用 / 限额」与「打开 a / b」 -->
**[配图建议]** 有规则态一张；数字列是用户最常对的地方。

### 单个应用详情

详情页用来对照「加入方案前」和「加入之后」的变化，常见内容包括：

| 内容 | 你能看到什么 |
|------|----------------|
| 今天 | 今日已用、与限额 / 打开次数的关系 |
| 时长（日均） | 加入前与加入后的对照，以及近期走势 |
| 打开（日均） | 同上，看打开次数是否下来 |
| 一周节奏等 | 更细的分布（若页面提供入口） |

详情底部一般有「去改规则」，会回到该应用在「方案」里的配置页。

页面上若出现一行淡字说明计量方式，大意是：

- **加入前**：按系统用量统计  
- **加入后**：按心锚实际放行后的使用计时；停在拦截页等待、或选择离开而未进入，**不计为使用时间**

### 「今日」不做的事

- 不在这里开关规则、改日限额数字（回方案）
- 不是完整的系统「屏幕使用时间」替代品；未加入方案的应用，加入后不再占用今日主列表

## 6. 日程锁

日程锁用来按**时间表**锁定一批应用：到了设定时段，这些应用打开时会被拦住。

入口：底栏「发现」→「日程锁」。

它和「方案」里单个应用的「时段锁」不同：

| | 方案 · 时段锁 | 发现 · 日程锁 |
|--|----------------|----------------|
| 管谁 | 某一个应用 | 一批应用（可跟随方案名单，也可另选） |
| 在哪设 | 该应用的配置页 | 发现 → 日程锁 |
| 适合 | 「这个 App 晚上别碰」 | 「工作日上午别刷这几个」 |

<!-- 图：发现页点进「日程锁」；空态「还没有时段锁」+「＋ 添加时段」 -->
**[配图建议]** 入口路径一张，或空态 + 添加按钮即可。

### 添加一条日程锁

1. 打开「发现」→「日程锁」。
2. 点「＋ 添加时段」。
3. 填写：

| 项 | 说明 |
|----|------|
| 名称 | 如「工作专注」（便于自己辨认） |
| 开始 / 结束 | 锁定的时间段 |
| 重复 | 每天、工作日，或自定义星期 |
| 锁定范围 | 是否跟随方案里已在监控的应用；也可「另选 App」补充 |

4. 保存后，列表中会出现该时段。当前正在生效的条目，界面会标出进行中状态。

到点后，范围内的应用再打开，会走拦截（通常为不可进入的拦住），直到该时段结束。

<!-- 图：添加时段表单（名称、起止、重复、锁定范围） -->
**[配图建议]** 编辑页一张，按表单字段顺序标注即可。

### 编辑与关闭

点列表中的某一条可编辑。若不需要，在编辑页删除或关闭（以实机选项为准）。

正在生效时若做削弱性改动，可能会多一步确认，避免误改正在执行的时段。

### 使用注意

- 方案里还没有任何应用、又未「另选 App」时，这条日程锁没有可锁对象，页面会提示先去方案添加或另选。
- 日程锁与方案中的日限额、打开次数可以同时存在；到点锁定时，以「此刻不能进」为准。

## 7. 权限与后台保活

### 权限分别做什么

| 权限 | 不做会怎样 |
|------|------------|
| 用量访问 | 看不到近 7 日用量；日限额等依赖时长的规则无法可靠工作 |
| 悬浮窗 | 无法在其它应用上方显示拦截页 |
| 无障碍 | 拦截页期间更容易被 Home / 最近任务绕过 |

入口都在「我」。缺项时会直接提示「有 N 项需处理」；全部正常时显示「监控正常」。

### 为什么有时「规则在，却拦不住」

常见原因不是规则写错，而是系统把心锚清出了后台，或限制了自启动。不同手机品牌的设置名称不同（如自启动、后台耗电、电池优化等）。

处理方式：

1. 打开「我」，看权限是否仍齐全。
2. 若提示与电池 / 后台相关，按页内指引进入**保活指南**（按你的手机品牌列出要开的开关）。
3. 按清单逐项打开后，再试打开一个方案中的应用，确认拦截页仍会出现。

说明书不在此罗列各品牌逐步路径（更新快、且易与你机型不符）；以 App 内保活指南为准。

<!-- 图：我 · 监控异常时的提示；保活指南清单（可裁品牌无关的示意） -->
**[配图建议]** 「我」缺项提示一张 + 保活指南列表一张。品牌逐步截图放在保活指南内维护，不必全塞进说明书正文。

### 建议的检查顺序

1. 用量访问、悬浮窗是否开启  
2. 无障碍是否开启  
3. 电池优化 / 后台限制是否放过心锚  
4. 再测：桌面打开方案中的应用 → 应出现拦截页
