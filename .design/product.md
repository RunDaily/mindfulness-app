## 1. 一句话

**少最多 3 个、多最多 3 个。少的看减少，多的看增加。门口只拦少的。**

人手配、能拦即可跑通。不提供 Agent、锚豆或 AI 改规则入口。

---

## 2. 产品原则

| # | 原则 | 含义 |
|---|------|------|
| P1 | 人先能配、能拦 | 开通主路径零 AI；空方案唯一主动作是「添加 App」 |
| P2 | 无 AI / 无锚豆 | 产品不暴露 Agent、校准对话、锚豆余额与扣豆 |
| P3 | 方案主表面 = 生效包 | 不是聊天、不是空「候选方案」 |
| P4 | 数字大于形容词 | 限额、剩余、次数写清楚；依据一行挂规则旁 |
| P5 | 门口是契约 | 规则写了就要执行；计数与拦截一致 |
| P6 | 拦截期间不露桌面 | Home / 进程列表 / 返回不卸门口；离开只能走页上动作 |
| P7 | 草图即骨架 | 真界面与草图同一分区，不另做展示页 |
| P8 | 界面不解说自己 | 不向用户解释架构、分区、设计取舍；能力靠布局与动作呈现，不靠旁白 |
| P9 | 体验为先 | 先让这一下好用，再谈仪式完整。能一步完成的不拆两步；诚实的路不再加第二道停顿 |

### 明确禁止

- 空列表时唯一 CTA 是「让 AI 生成」
- 用户可见「和 AI」「按这个调」「按用量校准」「锚豆」
- 「候选方案」作开通主路径
- 把旧意图门问卷、美德意图、搜索 Tab 当作开通默认
- AI 改规则（含确认后写入的 Agent 路径）
- 没有用量就不能添加 App
- 无限制加入少碰
- 对多碰设门口 / 呼吸 / 次数 / 日限
- 同一 App 同时在少和多
- 把「出去走走」这类无系统用量的事写成今日多碰行
- 拦截页期间把用户放回桌面或进程列表并卸掉盖层（手势可能闪一下，须立刻拉回）
- 用户可见文案写设计理由（如「规则只在这里改」「开关不被半屏盖住」「不是开通门槛」）
- 设置暴露「拦截背景」等调试项

## 3. 双环

| 环 | 职责 |
|----|------|
| **OS** | 打开瞬间执行器械；门口盖层；拦截期间吞三键（依赖无障碍）；计时与触顶 |

## 4. 三 Tab

| Tab | 职责 | 空态主动作 |
|-----|------|------------|
| **今日** | 镜子：少看剩余与减少，多看今日量与增加 | 去方案 |
| **方案** | 工坊：少花名册（器械）+ 多花名册（只看着） | ＋ 少 / ＋ 多 |

### 页面地图

```

方案 ── ＋ 少 / ＋ 多 ──› 名单 ──› 配置 / 加入
     ── 少/多行 ──› 同上详情
     └─ 近 7 日（未加入）──› 轻详情

我（健康）── 监控正常 ›
     ├─ 设置 ── 外观 · 胶囊 · 试验(试玩) · 清除数据
     ├─ 和小锚聊 ── 反馈（人工，非 AI）

     ── 多：不拦
```

**用量分层：** 新用户今日 = 机上热（系统时长 + 打开频次，只呈现；副文可挂「八成在前 N 个」）；管起来后明细沉到 App 详情，旁观未加入的仍在方案「近 7 日」。**配置页定目标（无用量立面）；详情页看变化。** 少详情顺序：
1. **时长（日均）** — 左监控前 | 右加入后；下挂时长变化图（贴宽约 12 柱，不横滑）

3. **今天** — 尺子 + 一周节奏 ›
4. **配置** — 顶线划界；今日契约 + 摘要 + 去改规则

左右标只用「监控前 / 加入后」。块标题用「时长（日均）」「打开（日均）」。无中间箭头、无差值旁白、无「点开细看」。全长横滑只在细看。草图：`.design/app-detail-tighten-sketch.html`。

## 4.1 双极 · 少 3 / 多 3

界面用「少 / 多」，不用「管控 / 正向」。

| | 少 | 多 |
|--|----|----|
| 每日盯 | 减少（已用 / 上限，辅相对昨日） | 增加（今日量，辅相对昨日） |
| 席位 | 最多 3 | 最多 3 |
| 对象 | App | 本阶段只收 App |
| 器械 / 门口 | 有 | 无 |
| 满席 | 先移再加 | 先移再加 |

**开通不锁满 6 席。** 一少一多就能跑。空席留着，让另一极被看见。不要第一天逼人填三个假的多。

**不配成一对。** 抖音不必绑读书。一个 App 只能在一侧。

**多不做日限额。** 「每天要读满 20 分」会把多变成另一座牢。没有昨日就不写对比。

**旧数据 >3 个少：** 先留着，不再能加，不自动删。

**和「想去的地方 / 有意义的事」分开。** 门口离开仍可跳到多名单里的 App，但本阶段不合并设置页。无系统用量的事（出去走走）不进今日多行。

## 5. 四件器械

| 器械 | 配置 | 触发 | 门口形态 |
|------|------|------|----------|
| **呼吸** | 秒数，0 = 关；中档默认 8s | 每次重新打开（未触硬界） | 倒计时后可「继续」；随时「不进去了」 |
| **次数** | 每日上限；中档默认 8 | 打开次数 ≥ 上限 | 硬挡：「今日次数已尽」· 只给离开 |
| **日限** | 每日分钟；中档默认 30 | 今日用量 ≥ 日限 | 硬挡（既有时长锁页） |
| **时段** | 起止 HH:mm | 落在窗口内 | 硬挡（既有时段锁页） |

**优先级（打开瞬间）：**

```
时段硬挡 > 次数尽 / 日限尽 > 软门 > 放行进入
```

**软门（少的拦截页）：** 见 6.1。按 App 分型：刷逛门（EXPLORE / CLASSIC）可叠呼吸；事务门（TASK，不含微信）无呼吸、两拍劝离。硬挡不分型。

**微信不加入监控。** 点选时提醒「微信不适合加入监控」，写入方案会被拒绝。真有事时门口碍事，无意识打开又拦不住。

**中档默认（批量添加）：** ≤8 次 · 日限 30 分 · 软门开 · 无时段。刷逛可短呼吸；事务门呼吸不生效。

## 6. 门口行为（OS 契约）

### 何时必须出门口

对**已启用规则**的 App，以下任一成立都要出门口，不得静默进入：

1. 冷启动打开  
2. 从桌面 / 其他 App 再进  
3. 会话已挂起再回切  
4. 短时间离开又回来（防抖未落定）  
5. 同包轮询发现「应出门却未在屏上」

**禁止：** 因「已有前台会话 / 挂起可恢复」且软门未过，就跳过门口直接进。

### 拦截页期间

| 用户动作 | 产品行为 |
|----------|----------|
| 刷逛门 · 倒计时未结束 | 左边是「等一下」，不能进 |
| 刷逛门 · 点「去搜」（倒计时结束且词够） | 拆门、深链落地、记一次打开；不建本次时长 |
| 刷逛门 · 点「打开」（已写下且已选时长） | 拆门、建带时长的会话、显示胶囊 |
| 事务门 · 第一拍点「离开」 | 记守住、回桌面 |
| 事务门 · 点「有事，进去」 | 进入第二拍（短时长） |
| 事务门 · 点 `1/2/3/5` | 拆门、建带时长会话、显示胶囊 |
| 点「不进去了」 / 「离开」 | 记守住（若适用）、回桌面 |
| Home / 最近任务 / 返回键 | **不卸门**；拉回门口（无障碍需开启） |
| 全面屏手势闪一下桌面或概览 | 立刻补盖 / 退回概览 |

离开门口的主路径只有页上的离开类动作，不是系统 Home。

### 6.1 软门 · 刷逛 vs 事务

草图：`.design/soft-door-two-kinds-sketch.html` · 刷逛细流 `.design/intercept-two-entries-sketch.html`

硬挡之后才进软门。分型沿用 `IntentGateKind`：`EXPLORE` / `CLASSIC` → 刷逛门；`TASK`（企业微信 / 支付宝等）→ 事务门。**微信不进少名单**（见上）。

#### 刷逛门

硬挡之后，先倒计时（中心秒数，「等一下」/「不进去了」）。倒计时结束，中心才换成入口。

| 进法 | 何时 | 倒计时后 | 本次时长 |
|------|------|----------|----------|
| **搜索直达** | 管理台目录启用且 prefer 落地，方案未关，本机可 resolve | 「搜索直达」+ 图标；至少两个字才「去搜」 | 不定 |
| **做什么** | 有深链，且点了「做什么」 | 写下后才出 `5 · 10 · 15 · 20`；选了才能打开 | 只这一次 |
| **直接打开** | 没有可靠深链 | 「打开」即可；「做什么」可忽略 | 不定 |
| **写下再开** | 没有深链，且写了字 | 有字才出时长；未选则「打开」转淡 | 只这一次 |

**禁止（刷逛）：** 跳过倒计时；没深链仍出搜索；空词当直达；还没写就逼选时长；搜索再问本次时长。

#### 事务门

草图：`.design/soft-door-two-kinds-sketch.html`

无呼吸；配置里呼吸秒数不生效。两拍：

1. **劝离**：标题「这一次先不必进」；「离开」叶色主行动；「有事，进去」雾色次一级。  
2. **短时长**：`1 · 2 · 3 · 5` 分；点芯片即进入并建带时长会话；可「返回」或「离开」。

不写意图，不摆常用操作芯片，不多问几道检验题。

**禁止（事务）：** 叠倒计时；无时长直进；问卷式芯片；单独「打开」确认；10/15/20 长档作默认尺子。

### 成功标准（门口）

- 规则写「≤8 次」且今日已尽 → 再开必见次数挡，不得放行  
- 刷逛 · 未触硬界 → 先见倒计时，「等一下」不能进  
- 刷逛 · 有深链且倒计时结束 → 才见搜索；词够可去搜，不见时长  
- 刷逛 · 写了字但未选时长 → 「打开」不可用  
- 事务 · 未触硬界 → 无倒计时；默认劝离；点短时长芯片才进并建带时长会话  
- 软门期间按 Home / 多任务 → 不得长期停在桌面或进程列表  
- 拦截页期间按 Home / 多任务 → 不得长期停在桌面或进程列表

## 7. 今日

### 首页

- 标题「今日」
- **无规则：** 副文「近 7 日 · 八成在前 N 个」（算不出则「近 7 日 · 这台手机」）；主表面 = 机上用量 Top（系统时长 + 行内打开次数）；点行 → 轻详情；底 CTA「去方案添加」  
- **有规则：** 副文 `N 个 App 在规则里`；主表面 = 规则行（名 · 器械摘要 · 已用/限额 · 打开 a/b）；底链「使用记录」  
- 有规则后**不**再占首页塞机上热（机上热回到方案「近 7 日」；点行仍进同一轻详情）  
- 探索「全量榜」仅为与今日热同源的次页，不是看见主路；时间感知器械已剔除 

### 用量口径（严谨 · 全产品遵守）

| 阶段 | 数据来源 | 用途 |
|------|----------|------|
| **加入监控前 / 外** | 系统 UsageStats / UsageEvents | 今日机上热（时长+打开）、轻详情（时长/打开可切）、方案近 7 日、加入前 7 日均（冻结基线）、配置页参考 |
| **加入监控后** | 心锚 `usage_records` 会话时长（含进行中会话） | 今日已用、日限硬挡、详情走势柱/折线、一周节奏（监控 App）、门口进入/离开 |

**为什么监控后不用系统：** 门口盖层期间目标 App 对系统仍常算前台，UsageStats 会把「停在拦截页」计进时长；心锚只在放行进入后记账，门口等待、硬挡离开不计使用。

**基线冻结：** 首次加入（或停用后再启用）时，把「前 7 个完整自然日」写入本地并永久保留：
- `baselineDailyAvgSeconds`：日均秒数（对照尺）
- `preJoinUsageJson`：逐日时长 + 打开快照（走势灰柱）；之后只读快照，不再问系统 UsageStats

缺快照的旧包：打开详情时 `ensureBaseline` 补记一次（系统窗口未清时仍可抓到）。后台同步：快照随监控档案上传（后续）；本阶段仅本地。

**用户可见说明（详情页一行淡字，不讲架构）：**  
「加入前按系统用量；加入后按心锚记录（门口等待不计时）」

禁止：监控后的今日/日限/走势再用 `max(系统, 心锚)` 混算；禁止把拦截盖层时长算成使用。

### App 今日详情（点行进入）

只读效果；改数字回方案配置页。**详情只留一眼，细看另页。**

| 块 | 含义 |
|----|------|
| 今日契约 | 已用 / 日限 · 打开 a/b |
| 走势预览 | 矮柱 + **折线**（约 10 日）+ 一句「比加入前少 x%」；**不标时长、不可抠日** |
| 字链 | `走势 ›` · `一周节奏 ›` |
| 口径 | 一行淡字（可更短） |

底动作：`去改规则` → 方案配置页。

### 走势细看页（从详情「走势 ›」进入）

草图：`.design/trend-peek-landscape-sketch.html`

| 块 | 含义 |
|----|------|
| 完整走势 | 加入前 7 日（系统）→ 今日（心锚）；柱 + 折线；**柱顶标分钟**；加入前均（冻结）· 日限虚线 · 加入竖线。**加入前柱与逐次同源**（前台会话之和，与探索详情一致）；事件已残缺时退回日合计并只展示「仅有日合计」 |
| 点日 | 展开该日逐次明细 |
| 逐次 | 加入前 = 系统前台条；加入后 = 心锚**放行使用**（不含门口离开、不含加入日系统种子）。特殊：仅有日合计、进行中 |
| 横屏 | **仅本页**允许；**独立构图**（左图铺满疏柱标量 + 左轴数值 · 右栏选中日）；不做「转横屏」芯片；离开恢复竖锁 |

未监控轻详情（从机上热点入）：近 7 日系统柱图 +「去方案添加」；不画日限线。

**逐次误差标注（克制）：** 段头区分「系统 / 心锚」即可；不要每行写「可能有误差」。缺逐次事件时写「仅有日合计」；门口离开写「未进入 · 不计时」。禁止加入后同日并排两套系统+心锚数字。

## 8. 方案

### 首页（严格自上而下）

```
标题「方案」
────────────────────────────────
A. 生效中
   行：App名 · 器械摘要 · ›
   空：一句「还没有规则」+「添加 App」
────────────────────────────────
B. 次要字链
   ＋ 少 · ＋ 多
────────────────────────────────
C. 近 7 日（淡）
   用量一览
```

（设计侧：近 7 日只作参考，不作开通门槛——不写进用户可见文案。）

### 添加 App

- 形态：**名单多选**（与方案同骨架），不是能力图标网格  
- 近 7 日可排序作参考，**不强制够门槛**  
- 「下一步 · 配置 N 个」→ **配置页**（见下）→ 人确认后才写入  
- **禁止**挑选后静默写成中档  

### 配置页（添加队列与点行共用）

草图：`.design/instrument-config-two-pillars-sketch.html`（主）· `.design/instrument-config-remove-sketch.html`（移出）· `.design/instrument-config-dial-first-sketch.html`（旧拨号）

**主业是定目标（拨开关与数字），不是看数。** 日均 / 打开次数 / 24h 热力**不**作配置页立面；看分布去今日 / 少详情。无用量权限仍可配、可保存。人手拨开关即可，无 Agent 建议行、无「按这个调」。

## 13. 使用中觉察（轻问）

草图：`.design/awareness-dual-track-flow-sketch.html`  
原则：**到场标记，不是使用中开课。** 成功是看见，不是答对、不是立刻离开。

门上命名之后，使用中最多再轻问 1～2 次，把自动化打断一瞬；与结束对照共用双轨文案（TASK / URGE）。

### 13.1 双轨问什么

| 轨 | 进门命名 | 使用中轻问 | 二选一 | SoftExit |
|----|----------|------------|--------|----------|
| **TASK** | 有实际事 | 「还在做「X」吗？」 | 还在 / 已经偏了 | 「似乎已经不在这件事上了」 |
| **URGE** | 诚实冲动 | 「还想待着吗？」 | 还想 / 可以停了 | 「可以收这一次了」 |

点「偏了 / 可以停」→ SoftExit（结束或再待一会儿，**不强制踢出**）。  
点「还在 / 还想」或超时未答 → 收岛，**不算失败、不惩罚**。

### 13.2 何时抛

| 条件 | 行为 |
|------|------|
| 无意图门 / 无命名 | 不抛 |
| 搜索直达（`IntentKind.SEARCH`） | 不抛（诚实入口不再加第二道停顿） |
| 单次时长 ≤5 分（事务短会话） | 不抛；结束对照即可 |
| 进门后前 3 分钟 | 不抛 |
| 有时长：约半程（夹在 4～20 分） | 首次轻问 |
| 无时长：约满 8 分钟 | 首次轻问 |
| 第二次 | 距上次至少再隔 12 分；每场最多 2 次 |
| 日限剩余 ≤5 分 / 会话将尽 / 紧急态 / 已展开岛 | 不抛（器械信号优先） |

岛在胶囊侧，约 5 秒自消。不挡操作中心。

### 13.3 禁止

- 使用中多轮问答、AI 开导、心灵鸡汤  
- 每分钟一问，或滚动 / 切 Tab 触发  
- 把「未回答」记成不正念或扣分  
- 对 URGE 问「还在做这件事吗」  
- 对搜索直达、≤5 分短会话套完整轻问  
- 用户可见文案解释「这是觉察训练」

### 13.4 验证（埋点漏斗）

1. 展示 → 有回应（还在/偏了，非纯超时）  
2. 点「偏了/可以停」→ 2 分钟内结束会话占比  
3. 有轻问 vs 无轻问：结束对照档位与时长分布  
4. 关陪伴 / 卸载率不因轻问抬升  

事件：`mid_check_show` · `mid_check_action` · `soft_exit_action`。

## 14. 验收清单（改完自测）

### 主路径

- [ ] 无网：能添加 1 个 App、配日限、打开被拦  
- [ ] 方案空态只有「添加」，没有「让 AI 生成」主 CTA  
- [ ] 今日空态指向「去方案添加」  
- [ ] 「我」健康态一行「监控正常」；缺权限时警告 + 异常行加重  
- [ ] 「我」菜单仅设置 / 和小锚聊 / 关于；试玩在设置·试验  
- [ ] 设置无「拦截背景」
### 门口

- [ ] 次数已尽再开 → 次数挡，不露 App  
- [ ] 刷逛 · 未尽 + 有呼吸 → 呼吸页，倒计时后才能继续  
- [ ] 点选微信 → 提醒「微信不适合加入监控」，不能加入  
- [ ] 事务（支付宝等）· 未尽 → 劝离拍；短时长点进  
- [ ] 拦截页 Home / 最近任务 → 门口仍在（或瞬间拉回）  
- [ ] 短离开再进 → 仍先过门口，不静默续会话跳过  

### 使用中觉察

- [ ] 写下意图进门 · 有时长 ≥8 分 → 约半程出现轻问岛；文案跟 TASK/URGE  
- [ ] 搜索直达进入 → 全程无轻问  
- [ ] 事务短时长（1～5 分）→ 全程无轻问  
- [ ] 进门 3 分钟内 → 不出现轻问  
- [ ] 点「已经偏了」→ SoftExit；点结束走结束确认；点再待则收岛  
- [ ] 轻问超时自消 → 不弹惩罚、可继续用  
- [ ] 每场最多 2 次；第二次至少隔 12 分  

### 旁路

- [ ] 今日点行 → 今日详情数字可读 → 去改规则落到对应 App  
- [ ] 校准无包 → 引导添加，不扣豆  

### AI

- [ ] 校准 / 对话失败不影响添加与门口
