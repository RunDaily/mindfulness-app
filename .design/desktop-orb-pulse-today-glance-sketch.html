框外 · 取舍

  • 主语不变：监控 in-app 仍先进 Pulse，不直接开 Hub与「未监控 in-app 看当前 App」同一原则；总览是旁路，不是首页
  • 旁路一行只报三数：监控合计 · 守住 · 进入与今日小票 peek 同口气；不加热力、不加四格芯片
  • 点开轻览：合计 + 当前占比一句 + Top 列表（标进行中）脚上「今日小票 / 打开心锚」；改规则仍回方案
  • 意图会话：胶囊默认不抬高；再点 / 长按才出今日一行避免进行中条带被总览挤掉
  • 数据：usage_records 监控口径，与 Hub / Pulse / 小票同源不混系统前台；未监控 App 不进这行合计
