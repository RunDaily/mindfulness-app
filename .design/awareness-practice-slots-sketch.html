SLOTS · EXTENSIBLE PRACTICE

觉察练习 · 插槽

总闸已落地。插槽要拆的是：何时抛、抛什么、看见了什么——三件事分开， 以后加练习包不必改胶囊主流程。

时机引擎 × 内容引擎 × 看见记录 · 总闸仍是一道

〇 · 原则

重在骨架，不在话术厚度。成功仍是看见，不是答对。

总闸不变：关 = 两幕全无。插槽只在开着时生效。
不改主路径：门口、计时、到点、器械紧急态优先于任何练习包。
二选一骨架：岛上永远是一句问 + 两个字动作；不做多轮、不做 AI 开导。
禁止灌进插槽：心灵鸡汤长文、每分钟一问、滚动/切 Tab 触发、 未回答扣分、用户可见「这是觉察训练」解说。

一 · 三引擎（代码边界）

今天的 MidSessionCheckPolicy / SessionAwarenessCopy 拆清职责。

WHEN

时机引擎

决不「抛什么」，只决「此刻能不能抛」。

  • 总闸 · 节奏 · 每场上限
  • 路径（刷一刷中途跳过）
  • 短会话 / 紧急 / 剩余不足
  • UI 互斥（展岛、锚提示）
WHAT

内容引擎

给定 path + mode + 练习包 → 一句问与二选一。

  • 内置包：路径回声（现网）
  • 可选包：停顿 / 收束 / …
  • 离开对照文案同属内容
  • variant 轮换仍在包内
SEEN

看见记录

答了什么不评分；只记「到场」。

  • mid_check show / action
  • end_compare 完成
  • 本周看见次数（只读）
  • 不入库惩罚字段
// 调用方（胶囊）只组合，不拼文案
if (TimingEngine.shouldAskNow(session, prefs)) {
  val card = ContentEngine.midCard(path, mode, pack, variant)
  showIsland(card)
  SeenStore.markShown(...)
}

二 · 插槽清单与分期

先拆接口，再填内容。V2 只做「能换包 + 看见一眼」。

S1 练习包
内容插槽。内置「路径回声」（现文案）；可选再挂 1～2 个包。 每包：中途 prompt/yes/no · 可选覆盖离开对照。选一个生效，不叠多包。
V2
S2 节奏档
时机插槽。现有疏/常；加「密」每 3 分钟 + 每场上限可配（默认仍 6）。 仍不做自定义分钟输入。
V2
S3 本周看见
记录插槽。配置页底部一行：本周轻问 N · 对照 M。 点进去可看极简列表（可选 V2.1）。不计分、不排行。
V2
S4 路径细开
时机插槽。意图 / 搜索 / 刷一刷 各自：中途开否 · 离开开否。 默认维持现网差分；高级，藏在「更多」。
V3
S5 按 App
时机插槽。某 App 强制静音练习，或只用某包。 易与器械配置打架——延后，且不作开通门槛。
以后
S6 锚提示
边界插槽。30s「你刚才说」今日属陪伴叙事，不进练习总闸。 若纳入：独立小开关「进门回声」，默认随练习或默认开——V3 再定。
V3

三 · 练习包长什么样

包是内容表，不是新交互形态。

每个包只提供：中途问句变体 + 二选一标签 +（可选）离开主问。 岛壳、5 秒自消、偏了→结束对照——全包共用，不许包自定义流程。

六 · 建议分期

V2 · 插槽可用

  • 拆 Timing / Content 接口
  • 内置路径回声 + 停顿包
  • 节奏加「密」
  • 本周看见一行
  • 发现副文带包名

V2.1 · 看见可回看

  • 本周看见轻列表
  • 每场上限可调（3/6/9）
  • 埋点漏斗看板自用

V3 · 细开

  • 路径级中途/离开开关
  • 锚提示是否纳入
  • 按 App 静音（谨慎）

七 · 明确不做

  • 包里自定义流程（多轮问答、强制踢出、呼吸作业）
  • 云端下发题库当开通依赖（可后做，V2 全本地）
  • 看见次数排行、勋章、扣分
  • 把练习包塞进门口 / 方案配置主路径
  • 默认打开任何新包——新包装上仍须人点选

八 · 拍板点

下面三句定了，就可以按 V2 开做。

1. V2 包清单：是否就「路径回声 + 停顿」两包？
2. 发现副文：开着时写「常 · 路径回声」，还是仍只写节奏？
3. 本周看见：V2 只一行数字，还是顺带轻列表？
