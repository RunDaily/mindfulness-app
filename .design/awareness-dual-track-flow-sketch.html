觉察双轨

进门同一次命名，分出两条线：有实际要做的事，就对照有没有跑偏； 只是诚实冲动，就对照待得有没有数。成功条件始终是到场，不是做对。

一次觉察 = 自动化快完成时，对「此刻正在发生什么」做了一次到场标记。 诚实命名冲动，和带着事进去，都算到场；跑偏了标出来，也算到场。未回答不算失败。
停住 → 命名 → 托住 → 使用中轻问（≤2）→ SoftExit → 结束对照

SoftExit

可以收这一次了停下来也是到场；想接着也行

结束对照

这一次，待得 · 有数 / 有点久 / 陷进去了不问跑偏；有点久才催「多待在哪了」

何时抛

  • 有意图门且已命名无门 / 无命名 → 不问
  • 进门满 3 分钟后安静窗内不问
  • 有时长：约半程（4～20 分）无时长：约满 8 分
  • 每场最多 2 次第二次至少再隔 12 分

不抛

  • 搜索直达诚实入口不再加第二道停顿
  • 单次时长 ≤5 分事务短会话；结束对照即可
  • 日限将尽 / 会话将尽 / 紧急态器械信号优先
  • 岛已展开或正在跑意图轨互斥，不叠

共用、不分轨的部分

停住拍、身/受/心轻提示、三出口（进入 / 到场离开 / 去做别的）、胶囊时间感知、 周回望里的结构——这些对两条线一样。分轨只发生在「命名之后还拿什么当镜子」。

契约与验收：`.design/product.md` §13 · 策略代码：`MidSessionCheckPolicy`。

怎样算有效

  1. 展示 → 有回应（非纯超时）· 事件 mid_check_show / mid_check_action
  2. 点「偏了 / 可以停」→ SoftExit → 2 分钟内结束 · soft_exit_action
  3. 有轻问会话的结束对照档位与时长分布，相对无轻问更诚实（不求更短）
  4. 关陪伴 / 卸载不因轻问抬升——若抬升，先减频，不加题
