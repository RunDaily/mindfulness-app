手机框里的话：只用「规则 / 开关 / 每天最多 / 不让进 / 你想怎样 / 建议改」。不说「器械」「Agent」「diff」「目标卡」。
四样能调的：打开前等一下 · 每天打开次数 · 每天最多多久 · 几点到几点不让进。
流程：今日一句读法 → 想改就聊 → 写成「你想怎样」→ 列出建议改 → 你点「就这样改」。配置页只帮填开关，你再保存。
不做：第四个底栏；拦截页里冒出聊天；没问清楚就改规则；空方案唯一按钮是「让 AI 生成」。
